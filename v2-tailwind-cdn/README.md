# Token Nyala — Tailwind CDN v2

Versi eksperimen menggunakan Tailwind CSS melalui CDN dan JavaScript vanilla.

## Struktur

```text
v2-tailwind-cdn/
├── index.html
├── script.js
├── assets/
└── README.md
```

## Menjalankan

Buka `index.html` langsung atau jalankan server lokal:

```bash
cd v2-tailwind-cdn
python3 -m http.server 4174
```

Kemudian buka `http://127.0.0.1:4174/`.

## Baseline

Versi ini dibuat terpisah agar tidak mengubah baseline vanilla pada folder utama.
