# Reference Audit — AI Token Top-Up

Date: 18 November 2026  
Scope: landing-page and purchasing experience references

## Domain Findings

| Input | Finding |
|---|---|
| Sumoku | `sumoku`, `sumoku.ai`, `sumoku.io`, `sumoku.com` do not resolve reliably. Likely misspelling or a private/unindexed product. Cannot assess via public web. |
| TokenKu | `tokenku.ai` is live. Website positions itself as “Satu Gateway untuk Semua Model AI”, emphasizing one gateway, 120+ models, API key management, budget monitoring, Rupiah payment, invoice, and tax invoice. |
| Helipod | `helipod.io` is live and in Indonesian/English. It is primarily PaaS hosting for app and AI deployment, not a pure token top-up store. |
| Netra Runtime | The provided `netraruntime` typo resolves to `netraruntime.com`, which redirects to `netra.sh`. It is high-performance inference infrastructure, focused on API integration and monitoring. |
| Opentauter | `opentauter.ai/.io/.com` do not resolve. Likely typo. Possible intended domain should be confirmed by the interview brief. |

## Observed Patterns

- TokenKu: broad feature-led gateway positioning; strong operational features for advanced users.
- Helipod: clear Indonesian infrastructure language and low-friction developer onboarding; hosting is more prominent than token purchasing.
- Netra: performance metrics, code snippets, and infrastructure credibility; less approachable for a first-time vibecoder.

## Opportunity for TokenNyala

TokenNyala should not compete on model count or technical vocabulary. The differentiation is a guided buying decision:

1. Explain value in ordinary language.
2. Start with intent (“Untuk belajar”, “Untuk bikin proyek”, “Untuk kerja tim”).
3. Translate nominal spend into usable AI sessions.
4. Display a clear one-screen purchase summary.
5. Show progress and delivery after payment.

## Messaging Guardrails

- Avoid unverified claims such as “unlimited”, exact token counts for every model, or guaranteed speeds.
- Explain that token usage varies by model and task.
- Use examples rather than technical metaphors.
- Keep Rupiah, payment trust, and receipt details visible.
