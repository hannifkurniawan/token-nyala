# TokenNyala Designer

Prototype landing page + top-up kredit AI untuk vibecoder pemula di Indonesia (ID/EN).

- **Mulai setiap sesi dengan membaca `PROJECT-MEMORY.md`** (status, keputusan, pertanyaan terbuka, pelajaran). Perbarui file itu di akhir sesi.
- Pengembangan aktif ada di `v3/` (mobile first, Tailwind v4). Ikuti `docs/v3-ground-rules.md`.
- v1 (root `index.html`/`styles.css`/`script.js`) dan v2 (`v2-tailwind-cdn/`) adalah arsip — jangan diedit.
- Komunikasi dengan user dalam Bahasa Indonesia.
