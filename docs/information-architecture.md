# Information Architecture

## Landing Page Sections

1. **Navigation**
   - Product wordmark
   - Cara kerja
   - Paket
   - Bantuan
   - Language switch
   - Masuk / Isi saldo

2. **Hero**
   - Benefit-led headline
   - Supporting explanation
   - Primary top-up action
   - Secondary usage guide
   - Small trust row

3. **Three-Step Explanation**
   - Pilih kebutuhan
   - Bayar
   - Mulai nyala

4. **Intent / Package Picker**
   - Belajar
   - Prototipe
   - Kerja
   - Dynamic recommendation and package cards

5. **Why It Works**
   - Plain language
   - One balance for AI tools
   - Local payment
   - Transparent usage estimate

6. **Live Example**
   - Mock project prompt and usage estimate
   - Clarifies that actual use varies

7. **Trust and FAQ**
   - Activation, refund, validity, payment support

8. **Final CTA**
   - Repeat core promise and purchase action

## Prototype Checkout Modal

- Package summary
- Email field
- Payment method selection
- Price breakdown
- Confirm button
- Success state

## Mobile Priority

Navigation collapses. CTA remains prominent. Package picker becomes horizontally compact or stacked. Checkout becomes a full-screen bottom sheet.
