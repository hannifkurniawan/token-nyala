# Project Brief — TokenNyala

## Product
TokenNyala is a bilingual Indonesian/English landing and top-up experience for people beginning to use AI in vibe-coding projects.

## Business Goal
Make it easy for first-time users to understand, choose, and purchase AI usage credit without knowing models, tokens, or API pricing deeply.

## Primary User
Indonesian beginner vibecoders, 18–35, building prototypes or personal projects while learning through visual tools and AI-assisted coding.

## Main User Problem
The user has two questions: “Berapa yang harus dibeli?” and “Apa artinya ini bagi proyek saya?” Existing AI marketplaces answer with technical model and credit terminology before helping with intent.

## Core Promise
**Nyala sekarang.** Top up AI credit in minutes, understand what a package can support, and continue building.

## Differentiators
- Intent-based package selection instead of model-first comparison.
- Plain-language estimates such as “cocok untuk 20–40 sesi coding kecil”.
- A 3-step flow: choose top-up, confirm and pay, return to balance.
- Indonesian payment trust cues and bilingual accessibility.
- Strong why: faster learning and fewer interruptions while building.

## Primary Action
**Isi saldo**

## Secondary Actions
- View usage guide.
- Calculate estimated needs.
- Switch language.

## Success Metrics
- Top-up CTA click-through rate.
- Package selection completion.
- Checkout start and payment completion.
- Drop-off between package selection and payment.
- Time to purchase.
- Support questions about “how much is enough”.

## Constraints
- Static HTML implementation for the interview prototype.
- Use illustrative, clearly labeled mock data.
- No real payment or account integration.
- Responsive desktop and mobile.
- Accessible, semantic, keyboard-friendly interface.
